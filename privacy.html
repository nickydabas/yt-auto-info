Privacy Policy

Last updated: 2026

This application ("YT Automation") is a personal, private tool built and used solely by its creator to automate uploading video content to YouTube channels that the creator owns. It is not distributed to, or used by, the general public.

What data this app accesses

This app requests the youtube.upload Google API scope only. This permission allows the app to upload videos and set metadata (title, description, thumbnail) on the authorized YouTube channel. It does not request access to Gmail, Drive, contacts, or any other Google service.

How this data is used

Access is used exclusively to upload videos created by the app's automation pipeline to the creator's own YouTube channel(s). No data obtained through this access is shared with, sold to, or processed by any third party.

Data storage

Authentication tokens are stored as encrypted secrets within the creator's private GitHub Actions environment and are not accessible to any other party.

Contact

For questions about this policy, contact the app owner via the GitHub account associated with this project.
